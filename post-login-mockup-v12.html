מה צריך כדי להטמיע את העיצוב בכל העמודים

6 צעדים מסודרים. אחרי שלב 3 הקונספט כבר עובד; שלבים 4-6 מלטשים. כל שלב עומד בפני עצמו — אפשר לעצור ולשחרר לפרודקשן באמצע.

1 תשתית

קומפוננטת AppShell משותפת

קומפוננטה חדשה components/shell/AppShell.tsx שמכילה: sidebar ימני, top-bar, content slot, mobile bottom-tabs. responsive — sidebar מוסתר מתחת ל-md, tab-bar מוסתר מעל.

  • AppShell.tsx + SideNav.tsx + MobileTabs.tsx + CoupleCard.tsx + ExpertMini.tsx
  • טוקני CSS חדשים ב-globals.css (canvas-grad, cta-grad, side-bg)
  • הוספת פונט Assistant ל-app/layout.tsx
  • 16 אייקוני SVG בספרייה משותפת
⏱ 4-6 שעות
2 ראוטינג

Layout מפוצל — shell vs naked

יצירת app/[locale]/(shell)/layout.tsx שעוטף ב-AppShell. כל ה-routes שמופיעים בניווט עוברים תחתיו. החריגים: /games/[slug], /mioshy-sex/[slug], ה-onboarding ו-checkout נשארים בעמודים עצמאיים מסך מלא.

  • העברת /my, /my/journey/*, /games, /mioshy-sex תחת (shell)
  • הגדרת app/(naked)/layout.tsx ל-game-in-play
  • middleware: re-route /my → /my/today (הומופוגי)
  • שמירת marketing pages, /auth, /pricing בלי shell
⏱ 3-4 שעות
3 דף ״היום״ החדש

החלפת /my בעמוד ״היום״

דף ראשי חדש app/(shell)/[locale]/my/today/page.tsx עם: focus-pill (מהמוקד), hero-card (השיעור הנוכחי), chat-row preview (latest expert msg), היסטוריה (5 אחרונים). שולף מאותם hooks שיש היום.

  • קומפוננטות: FocusPill, CurrentLessonHero, ChatRowPreview, HistoryList
  • שאילתות: getCurrentItem + getLatestExpertMessage + getCompletedItems
  • 3 CMS keys חדשים (כותרת היום, eyebrow, sub)
⏱ 6-8 שעות
4 השיעורים + צ׳אט

הרחבת ״השיעורים שלי״ ו״צ׳אט עם מומחה״

דף ״השיעורים שלי״ מציג אבחון בראש (assess-row), פעיל עכשיו, הושלמו, בקרוב. ״צ׳אט עם מומחה״ הופך לעמוד מלא עם conversation + composer (לוקח מ-JourneyAnalysisCard ו-ChatRow הקיימים).

  • אבחון = link ל-/journey/assessment-summary (קיים)
  • שימוש חוזר ב-journey-content/queries.ts הקיים
  • צ׳אט: ניצול הקיים messages.ts + sender hook
⏱ 5-7 שעות
5 שיתוף + הגדרות

שני עמודים חדשים

שיתוף: ניצול PartnerShareCard הקיים — מעצבים מחדש ל-ghost-pair + 4 ערוצים. הגדרות: רשימת set-rows שמובילים למקומות הקיימים (פרופיל, התראות, מנוי). מוסיפים התנתקות ב-sidebar (לא בהגדרות).

  • הזזת מנוי וחיוב פנימה להגדרות (קיימים מ-/account/billing)
  • action חדש: logout button → supabase.auth.signOut()
  • קומפוננטה Settings-Row משותפת
⏱ 4-5 שעות
6 Badges + notification state

צבירת badges דינמיים

hook useNavBadges() שמחזיר { lessons: 1, chat: 2, partnerShareNew: true }. הסייד-בר ו-tab-bar קוראים ממנו. ספירת unread בצ׳אט קיימת ב-fresh-replies.ts, רק להוסיף את ״1 שיעור חדש״.

  • שאילתה — חדש מאז last_seen_at של profile
  • ״סיום צפייה״ — POST מה-client מוריד את ה-counter
  • גם /my/today מציג ״נפתח עכשיו״ על השיעור הנוכחי כשרלוונטי
⏱ 3-4 שעות

  • !
    iOS Safari + safe-area. ה-mobile tab-bar חייב env(safe-area-inset-bottom) כפי שכבר הוטמע ב-MobileServicesBar. אחרת — סקרול גורם לחור שקוף.
  • !
    לחיצה על משחק מתוך הקטלוג. ה-shell צריך לעטוף את /games (catalog) אבל לא את /games/[slug]. הראוטר ב-Next App Router דורש 2 layout groups (shell) ו-(naked).
  • !
    ״עוד״ במובייל מסתיר את שיתוף. לוויראליות זה קריטי. בנוסף לטאב — להוסיף קארד "שתפו עם בן/בת זוג" בדף ״היום״ עד שהמשתמש שיתף.
  • !
    ״התקדמות״ ו״האבחון״ ירדו מהניווט. אם משתמשים קיימים מחפשים אותם — להפנות אוטומטית: /my/progress → /my/today, /my/assessment → /my/lessons#assessment.
  • !
    ביצועים. SideNav, ExpertMini, badges — צריך לוודא שהם נשארים static-ish ולא מטריגרים render-loop על כל מעבר טאב. Sticky + memo.
