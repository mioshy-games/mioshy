# PR: דשבורד מובייל — POC (זוגות) + תשתית ניווט

branch: `dashboard/mobile-refactor` · שלב 1 מתוך הריפקטור.

## מה השתנה

חלק ראשון מתוך ה-POC שאישרת (אזור "הזוגות שלי"): תשתית הניווט המובייל + רשימת הזוגות כקלפי אקורדיון עם חיפוש חכם. **הדסקטופ לא נגע** — כל השינויים מאחורי `md:hidden`, והרשימה הקיימת נשארת ב-`md+`.

### קבצים חדשים
- `components/dashboard/BottomNav.tsx` — bottom nav מובייל בלבד (`md:hidden`). 5 טאבים: סקירה · זוגות · מסע · משחקים · עוד. טאב "עוד" פותח Sheet עם שאר הסקציות. badge להודעות ממתינות על "זוגות". כל יעד לחיץ ≥56px, עם safe-area בתחתית.
- `components/dashboard/journey/CoupleCardList.tsx` — רשימת אקורדיון מובייל. שם + סטטוס תמיד גלויים בלי גלילה; פתיחה חושפת התקדמות, פעילות אחרונה, וקוד צימוד + פעולות (כרטיס הזוג / אימייל) בגובה 44px+.
- `app/dashboard/journey/clients/ai-search.ts` — server action לחיפוש חכם. שאלה בעברית → spec סינון קטן ומוגדר (לא SQL, לא נוגע ב-schema). משתמש ב-Claude Haiku דרך אותו fetch קיים (`lib/ai/`), בלי תלות npm חדשה. **graceful**: כל כשל → null → נפילה לחיפוש טקסט רגיל.

### קבצים ששונו
- `app/dashboard/layout.tsx` — מרנדר `<BottomNav>` + `pb-24` למובייל כדי שהתוכן לא יוסתר. דסקטופ ללא שינוי.
- `app/dashboard/journey/clients/page.tsx` — בלוק מובייל חדש (`md:hidden`) עם `CoupleCardList`; הרשימה הקיימת עטופה ב-`hidden md:block`.
- `lib/admin/i18n.ts` — 2 מפתחות חדשים: `nav.couples` (זוגות), `nav.more` (עוד), עברית + אנגלית.

## איך לבדוק (מובייל)
1. `git checkout dashboard/mobile-refactor` ואז `npm run dev`.
2. פותחים את `/dashboard/journey/clients` בדפדפן ברוחב מובייל (DevTools → iPhone, או טלפון אמיתי).
3. בודקים: bottom nav קבוע למטה, טאב "זוגות" מסומן; כל זוג = קלף עם שם + סטטוס; הקשה פותחת/סוגרת; כפתורי הפעולה ≥44px.
4. חיפוש: מקלידים שם ולוחצים Enter (טקסט). מקלידים שאלה ("מי לא סיים") ולוחצים על כפתור ה-AI (✦) — מופיע צ'יפ "סינון AI פעיל · N תוצאות". בלי `ANTHROPIC_API_KEY` → נופל לחיפוש טקסט עם הודעת toast.
5. דסקטופ (≥768px): מוודאים שאין שינוי — הסייד-בר והרשימה הישנה כרגיל.

## תיקונים — סבב 2 (אחרי סקירה ב-376px)
1. **עברית** — `/dashboard` ו-`/dashboard/journey/clients` עברו ל-i18n (getAdminLocale + t). "Clients"→"לקוחות", "Dashboard"→"לוח בקרה" וכו'. נוספו מפתחות `home.*`, `clients.*`, `common.*` בעברית+אנגלית.
2. **Layout שבור** — שורש ה-layout היה `flex` (row), והכותרת המובייל של ה-Sidebar ישבה כ-flex sibling ליד התוכן ואכלה חצי מהרוחב. תוקן ל-`flex-col md:flex-row` + `w-full` ל-`<main>`. (זה גם פתר את בעיות 4 ו-5.)
3. **שם לא נראה** — נוסף fallback (`label → קוד צימוד → "זוג ללא שם"/"ללא שם"`), השם תמיד bold מעל הסטטוס. (הוסתר קודם בגלל ה-layout השבור.)
4. **כותרת באמצע** — אותו תיקון layout מצמיד את ה-header המובייל למעלה; נוסף `sticky top-0 z-30` ל-Sidebar mobile bar.
5. **שדה AI** — עוצב מחדש לשדה אחד גלוי עם האייקונים בתוכו (חיפוש בהתחלה, כפתור ✦ בסוף), placeholder "חפש או שאל שאלה...".
